Wolfenstein 3D for the fx-CG50

Kelli's fx-9860 game, running on the fx-CG50 / Graph 90+E. The conversion happens in your browser: nothing is uploaded.

1. Get the game

Download file 2 (the SH4 version) of Last Wolfenstein 3D by Kelli on Planète Casio.

2. Convert it

3. Copy it to the calculator

Connect the calculator with USB, choose USB Flash, copy Wolf3D.g3a to it and disconnect. Wolf3D appears in the main menu.

How it works

Both calculators run SuperH code, and their operating systems load add-ins at the same address, so the game's own code runs unchanged. A small shim takes the place of the fx-9860's system calls, draws the 128×64 screen three times larger, and slows the game to the pace it had on the fx-9860. This page adds the shim to the copy of the game you choose; it contains no part of the game itself.
